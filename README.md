### Technical Architecture
- **Framework**: React 18 & TypeScript
- **Bundler & Tooling**: Vite 5
- **Design Tokens**: Tailored Tailwind CSS (Obsidian, Signal Cyan, Signal Gold/Amber, Steel)
- **3D Dimensional Core**: Interactive Three.js spatial canvas with 360° tilt and verified credential flip card

- **Quality & CI/CD**: GitHub Actions pipeline for automated linting, TypeScript typecheck, and production bundle verification
